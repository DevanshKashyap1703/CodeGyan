# CodeGyan 🚀

A free coding learning platform inspired by FreeCodeCamp. Learn programming, web development, and computer science fundamentals completely free!

## Project Structure

```
CodeGyan/
├── frontend/           # React/Vue.js Frontend Application
├── backend/            # Node.js/Python Backend API
├── docs/               # Documentation
└── README.md          # This file
```

## Features

- ✅ **Free Learning Courses** - Interactive coding tutorials
- ✅ **Progressive Difficulty** - From beginner to advanced
- ✅ **Code Editor** - Built-in IDE for practice
- ✅ **Project-Based Learning** - Real-world projects
- ✅ **Community** - Connect with other learners
- ✅ **Certificates** - Earn certificates after completion

## Tech Stack

### Frontend
- React.js / Next.js
- Tailwind CSS
- Monaco Editor (Code IDE)
- Redux/Context API

### Backend
- Node.js (Express) / Python (Django/FastAPI)
- PostgreSQL / MongoDB
- JWT Authentication
- REST API

## Getting Started

### Frontend Setup
```bash
cd frontend
npm install
npm start
```

### Backend Setup
```bash
cd backend
npm install  # or pip install -r requirements.txt
npm run dev  # or python manage.py runserver
```
